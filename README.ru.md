# mercurius-peer

[English](README.md) | **Русский**

Связь агента на AMPHP с другими агентами по A2A v1.0: агента узнают по его ключу ECDSA P-256, а не по общему токену.
Клиент берёт карточку соседа и проверяет, что карточка доказывает свой ключ, отправляет задачу, спрашивает её
состояние или отменяет — по одному WebSocket, рукопожатие которого доказывает оба ключа, или по HTTP с подписью каждого
запроса — и отправляет файлы раньше сообщения.

Часть проекта [Меркурий (Mercurius)](https://github.com/opencck/mercurius) — автономного персонального агента. Пакет не зависит от приложения Меркурия и может использоваться отдельно.

**Статус:** используется Меркурием между его экземплярами. Сторона сервера (кого пускать, запуски, которые отвечают
соседу, хранилище файлов) живёт в приложении: она зависит от его участников, политик и агентского цикла.

**Стек:** PHP 8.2+, AMPHP v3, `amphp/http-client` v5, OpenSSL.

## Части

| Класс | Что делает |
|-------|------------|
| `AgentIdentity` | Ключ P-256: создать, прочитать из PEM, подписать, проверить, отпечаток; какие данные покрывает каждая подпись |
| `A2aClient` | Карточка (с доказательством ключа), `SendMessage`, `GetTask`, `CancelTask`, файлы раньше сообщения; WebSocket или подписанный HTTP — по карточке |
| `A2aSocket`, `A2aChannel` | Одно соединение JSON-RPC поверх любого канала после рукопожатия обоих ключей; запросы в обе стороны и уведомления |
| `A2aLinks` | Живые соединения с другими агентами, в обе стороны |
| `A2a` | Коды ошибок, пределы и схема файлов, текст сообщения, выгрузка multipart |
| `PeerEndpoint`, `IdentityKeys` | Что даёт приложение: свою запись о соседе; ключи, которые оно показывает выбранным соседям |

## Использование

```php
use Mercurius\Peer\A2aClient;
use Mercurius\Peer\AgentIdentity;

$me = AgentIdentity::fromPem($pemKeptByYou);
$client = new A2aClient($httpClient, $me);
$card = $client->provenCard('https://neighbour.example.com');   // исключение, если карточка не доказала ключ
$task = $client->send($neighbour, $token, bin2hex(random_bytes(8)), 'Сделай сводку отчёта', 0, []);
```

Тексты ошибок — на английском; свои задаются один раз: `Mercurius\Peer\Texts::translateWith(fn(string $key): string => ...)`.

## Проверки

`composer check` — PHPUnit, PHPStan (уровень max) и Psalm (уровень 1). Клиент и сервер вместе проверяет Меркурий.
