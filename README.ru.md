# mercurius-peer

[English](README.md) | **Русский**

Протокол связи экземпляров Меркурия по WebSocket: карточка агента, задача, поток статусов, итог, отмена и переподключение — клиент и сервер. Один экземпляр может использовать другие как своих агентов и субагентов.

Часть проекта [Меркурий (Mercurius)](https://github.com/opencck/mercurius) — автономного персонального агента. Пакет не зависит от приложения Меркурия и может использоваться отдельно.

**Статус:** код пока в основном репозитории, в [`src/App/Peer/`](https://github.com/opencck/mercurius/tree/master/src/App/Peer) (A2A по WebSocket и HTTP, ключи агентов, делегирование со сроком и отменой), и переезжает сюда следующим.

**Стек:** PHP 8.2+, AMPHP v3.
